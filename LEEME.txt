GESTIÓN INTEGRAL - SITIO WEB ACTUALIZADO

Incluye la sección del equipo y tarjetas descargables PNG de 1050 x 600 px.

ARCHIVOS
index.html: contenido y estructura.
style.css: estilos y colores.
app.js: módulos, galería y video.
team.js: nombres, carnets, enlaces y tarjetas del equipo.
assets/: imágenes, logo UDB y video.
vendor/: Bootstrap local y su licencia.

EDITAR LINKEDIN
Abre team.js en Visual Studio Code. En teamMembers, completa linkedin: ''
con el enlace correspondiente, por ejemplo:
linkedin: 'https://www.linkedin.com/in/usuario'
Si está vacío, el botón no se muestra. También puedes completar portfolio.
Los correos se forman con el carnet y @alumno.udb.edu.sv.

VER EN TU COMPUTADORA
Extrae el ZIP completo en una carpeta. Abre esa carpeta en Visual Studio Code
y ejecuta index.html con Live Server. Alternativamente, si tienes Python,
abres una terminal dentro de la carpeta y ejecutas:
python -m http.server 8000
Luego abre http://localhost:8000.
Usa un servidor local para probar la descarga de tarjetas; abrir mediante
file:// puede restringir la exportación de imágenes en algunos navegadores.

SUBIR A UN HOST
Sube index.html, style.css, app.js, team.js y las carpetas assets y vendor
a la carpeta pública del hosting, conservando su estructura.
index.html debe quedar en la raíz pública (por ejemplo public_html).
No necesitas instalar Node ni compilar: es un sitio estático.

El sitio es informativo; no incluye el backend del sistema de gestión.
El video y las pantallas contienen datos ilustrativos.
